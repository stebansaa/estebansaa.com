# estebansaa.com

Personal site of Esteban Saa: a creative showcase of my skills for people interested in hiring me, and the front door to my consulting services.

## Stack

- [Astro](https://astro.build) — static HTML, zero JS by default
- [Three.js](https://threejs.org) — hero scene, lazy-loaded after first paint (skipped for reduced motion / Save-Data / no WebGL)
- Hosted on Cloudflare Pages

## Develop

```sh
npm install
npm run dev      # http://localhost:4321
npm run build    # outputs to dist/
npm run preview
```
